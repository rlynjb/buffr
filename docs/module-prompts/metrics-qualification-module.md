# Metrics & Qualification Module

<!-- Source: Master V6 Steps 3–4 -->

## Responsibility

Calculate or organize relevant product-performance metrics and qualify them against the strongest appropriate baseline.

Establish:

1. the current metric values,
2. the baseline used for comparison,
3. the magnitude and direction of change,
4. the qualification status of each important metric,
5. whether the available evidence is sufficient for interpretation.

---

## Reasoning Mode

**HYBRID**

Use deterministic methods for:

- metric calculations,
- absolute changes,
- percentage changes,
- application of established thresholds or rules.

Use contextual reasoning when:

- determining whether periods are comparable,
- assessing evidence quality,
- interpreting results where no validated threshold exists.

Separate numerical magnitude from confidence in the evidence.

---

## 1. Calculate Core Metrics

Use validated source data when available.

### Conversion Rate

**Conversion Rate = Orders ÷ Views**

If another denominator is required by the source data, explicitly identify the denominator.

Do not silently substitute visits for views.

### Favorite Rate

**Favorite Rate = Favorites ÷ Views**

### Click-Through Rate

**CTR = Clicks ÷ Impressions**

### Revenue Per View

**Revenue Per View = Revenue ÷ Views**

### Average Order Value

**Average Order Value = Revenue ÷ Orders**

### Return on Ad Spend

**ROAS = Ad Revenue ÷ Ad Spend**

Do not interpret ROAS as profitability unless sufficient cost information exists.

### Change

When comparing a current metric with a valid baseline, calculate the absolute and/or percentage change consistently.

Do not estimate mathematical results when the required inputs exist.

---

## 2. Select the Comparison Baseline

Use the strongest available baseline.

Prefer, in order:

1. baseline immediately before the current experiment,
2. previous comparable period for the same product,
3. longer-term historical average for the same product,
4. comparable previous experiments on the same product,
5. comparable products within the same shop,
6. validated external benchmarks when internal evidence is insufficient.

Always state which baseline is being used.

If no valid baseline exists, report that explicitly.

---

## 3. Assess Comparison Quality

Before qualifying a metric, consider whether the comparison is reasonably comparable.

Relevant context may include:

- period length,
- listing age,
- traffic volume,
- order volume,
- advertising activity,
- seasonality,
- marketplace demand,
- competition,
- recent listing changes,
- experiment duration.

Do not treat non-comparable periods as equivalent.

---

## 4. Qualify Each Metric

Use one of:

- **IMPROVED**
- **DECLINED**
- **STABLE**
- **INCONCLUSIVE**
- **NOT AVAILABLE**

Base qualification on:

- the current value,
- the selected baseline,
- the calculated change,
- available qualification rules,
- evidence quality.

When validated numerical thresholds do not exist, use cautious qualification rather than inventing one.

Examples:

- appears to have improved,
- shows a possible decline,
- appears approximately stable,
- insufficient evidence exists to classify the change.

---

## 5. Separate Magnitude From Confidence

Do not assume that a large percentage change automatically represents strong evidence.

Consider the underlying volume.

For example:

A large conversion-rate increase based on very few views or orders may still be **INCONCLUSIVE**.

Report the numerical change separately from the confidence in that change.

### Confidence Rules

**[TO BE RESEARCHED / DEFINED]**

---

## Output

### Calculated Metrics

For each relevant metric:

- metric name
- current value
- source inputs

### Baseline Comparison

For each relevant metric:

- baseline value
- baseline source
- absolute change
- percentage change when applicable

### Metric Qualification

For each relevant metric:

- qualification status
- evidence quality
- relevant contextual factors

### Comparison Limitations

Identify any issues affecting comparability or confidence.

### Unresolved Qualification Needs

Identify missing thresholds, sample-size rules, duration requirements, or other qualification criteria that may require later research.

---

## Boundary

Stop after calculating and qualifying performance relative to an appropriate baseline.

Do not diagnose the cause of performance or recommend changes.
