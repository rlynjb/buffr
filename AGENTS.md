## AIPE learning workflow

When the user asks to run AIPE, do not only modify code or produce a short summary.

Create a documentation folder under:

docs/aipe/<topic-name>/

Required files:

- overview.md
- architecture.md
- dry-run.md
- concepts.md
- questions.md

The user learns best through:
- ASCII diagrams
- dry runs
- first-principles explanations
- comparing patterns from different angles
- explaining why an abstraction exists
- tracing how one file affects another file

The output should be informative enough to become study material.
Prioritize clarity, examples, and mental models over short answers.
